# CRWN Clothing

Educational React e-commerce application developed as part of a React course.

## Tech Stack

- React 18
- React Router
- Firebase
- Sass
- Styled Components
- React Context API

## Features

- Product categories and shop views
- Client-side routing
- Reusable React components
- Authentication and Firebase integration
- Shared application state with Context API
- Responsive styling

## Status

Completed educational project. This repository is kept as part of my frontend development learning path.
